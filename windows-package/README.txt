ReceiptVision - نسخه ویندوز بدون نیاز به داکر
================================================

این پوشه چیست؟
-------------
این کل برنامه است. نه چیزی نصب می‌شود، نه به اینترنت نیاز دارد
(فقط برای دانلود همین فایل یک‌بار اینترنت لازم بود).

روش استفاده (فقط ۲ قدم):
------------------------
۱. روی Start.bat دو بار کلیک کنید و صبر کنید تا بنویسد [OK].
۲. پنجره برنامه باز می‌شود: دکمه «ساخت حساب» را بزنید و وارد شوید.
   بعد عکس رسید را انتخاب کنید و دکمه «استخراج متن» را بزنید. تمام!

خاموش کردن:
------------
روی Stop.bat دو بار کلیک کنید. اطلاعات شما پاک نمی‌شود.

نکته‌ها:
--------
- اگر ویندوز موقع اجرا اجازه خواست، چون برنامه فقط روی
  کامپیوتر خودتان کار می‌کند، می‌توانید Cancel را بزنید.
- این پوشه را پاک نکنید (رسیدها داخل پوشه data همین‌جاست).
- برای انتقال به کامپیوتر دیگر، کل پوشه را کپی کنید.
